# RATIFY — the Constitutional Convention, but it's a quiz

A self-quiz for POLS-1101 Ch 1–3 built from the vault glossary
(`College/Fall 2026/POLS-1101 Glossary Ch1-3.md`, 61 terms, verbatim).
Thirteen states sit on the floor in real ratification order (Delaware
Dec 7 1787 → Rhode Island May 29 1790). Each question is one state's vote:
answer right, that state ratifies (amber chip); wrong, it rejects
(struck through). You need 9 of 13 — the actual historical threshold.
Four question types: definition→term, term→definition, true/false, and
which-chapter (only offered for terms whose name is unique to one chapter,
so the chapter tag can't leak the answer). End screen: big X/13, a verdict
("Ratified." / "Shay's Rebellion by morning."), and a review list of every
term that rejected you. Practice only — no quiz or exam content.
